# MEMOIR Worker Contract

These instructions apply to every coding agent operating in this repository.

## Mission

Produce an audit-ready, same-prompt ALFWorld rollout pilot from the pinned
`langfengQ/verl-agent` revision. Preserve exact evidence. Do not claim causal
effects from observational trajectories.

## Required reading order

1. `CLAUDE.md`
2. `WORKER_INSTRUCTIONS.md`
3. The machine-specific file in `worker_tasks/`
4. `docs/reproducibility/trajectory-audit.md`
5. `docs/reproducibility/original-methods.md`
6. `docs/research/trajectory-audit-findings.md`

## Non-negotiable rules

- All code comments and documentation must be in English.
- Unit tests are named and described as tests, never as experiments.
- Never delete raw rollouts, manifests, logs, or failed-run evidence.
- Never substitute a summary for exact policy-visible context or raw evidence.
- Keep `anchor_obs` distinct from policy-visible model context.
- Every code change must be recorded in the machine result JSON.
- Do not upload, push, open a pull request, or transmit machine data.
- Do not expose credentials or environment secrets in logs or screenshots.
- If a requirement cannot be satisfied, stop the affected stage, record the
  blocker, and continue with all safe independent checks.
- The final required deliverable is a single local SVG generated by
  `scripts/render_handoff.py`; do not manually edit that SVG.

## Completion condition

The task is complete only when tests have run, the export readiness validator
has run, hashes have been recorded for available artifacts, and
`reports/<machine-id>/handoff-summary.svg` has been generated and visually
checked at 100% zoom.
